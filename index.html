IOne window

One app, see every file.

Stop jumping between a dozen apps. Folio holds everything in one window.

  1. code reading

    Elegant code reading, fully yours.

    Every popular programming language is ready. Crisp syntax colors, tidy indentation — code reads like prose, not a wall of text.

    • Covers every popular programming language
    • Comfortable sizing and spacing for long reading
    • Browse multiple folders side by side
  2. image viewer

    All image formats, just one viewer.

    Even huge files open fast. Phone shots, web images, GIFs, vector files — open, zoom in, and read the details.

    • Phone shots, web images, GIFs and vectors
    • Huge files open fast
    • Click through a whole folder from the sidebar
  3. markdown

    Markdown that flows like natural writing.

    Write naturally, see results instantly. Headers, lists, tables, code blocks render as you type — no preview pane required. Offline translation built in.

    • What you write is what you see
    • Math, diagrams, code blocks rendered beautifully
    • Translate locally — no internet required
  4. office & pdf

    Office docs and PDF, open in one click.

    No waiting for Office to launch. Word, Excel, PowerPoint, Pages, Numbers, Keynote and PDFs — double-click and read, clean and clear.

    • Word, Excel, PowerPoint, Pages, Numbers, Keynote
    • Search inside PDFs, jump by outline, highlight matches
    • Long documents open instantly, scroll smoothly
  5. video player

    Every video, one smooth player.

    All major formats play instantly — no conversion needed. Keyboard shortcuts, subtitles, picture-in-picture, and easy on the battery.

    • Smooth playback, easy on the battery
    • Picture-in-picture when you need it
    • Audio files show their waveform

FAQ

Still curious?

Folio is a universal file viewer for Mac. One app opens documents, spreadsheets, slides, PDFs, notes, code, images, music and video — replacing the dozen apps you usually juggle, in one quiet, focused window.

macOS Preview is built for a quick glance. Folio is built to stay: tabs, cross-file search, editing for notes and Word files, and 15 reading themes — turning "peek and close" into "open and work".

Yes. Markdown notes, Word (.docx) files and code are editable, and .docx is saved back as .docx. Other formats, such as PDF, spreadsheets and slides, open for reading and searching.

Folio supports macOS 15 and above, and runs smoothly on every Mac.

Folio quietly prepares when you open a folder, then only catches up on changes. Even folders with 10,000 files respond as you type — you won't notice it working.

Everything happens on your Mac. Folio never uploads your files anywhere — it is the default, with no cloud toggle to switch off.

The Mac App Store edition is free to download.

A separate build of Folio, distributed directly instead of through the App Store. It adds a terminal, Git, AI command-line tools, tasks and side-by-side translation, and includes automatic version snapshots. Everything in the chapters above is there too.
