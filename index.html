Still curious? Here you go.

What's the difference between Folio and Folio Pro?

Same core: 14 formats, tabs and multi-root workspaces, full-text search, Markdown / Word / code editing, themes and localisation. Pro adds the terminal, full Git, the AI CLI hub, automatic snapshots, all translation backends and tasks — features that need to spawn processes, which the App Store sandbox doesn't allow.

Will editing a Word document break its formatting?

No. Folio round-trips the underlying OOXML: a .docx goes in and a .docx comes out, with paragraph styles, tables, images and watermarks preserved.

Do my files ever leave my Mac?

Viewing, searching and editing all happen on your Mac. Translation can use Apple's on-device engine or local Ollama; text is only sent to a service if you choose Gemini CLI or Google Cloud as the backend in Pro.

Do I need to know Git to use Snapshots?

No. The interface only talks about versions, notes, sync and restore. Snapshots are taken automatically and thinned Time-Machine style — everything for 24 hours, daily for 7 days, weekly for 30 days, monthly after that. Locked versions are never removed.

Does the AI CLI hub read my conversations?

It doesn't parse or store messages. Folio only lists the local session history each CLI already keeps so you can resume from the sidebar; the content stays managed by Claude Code, Codex and Antigravity themselves.

System requirements and price?

macOS 15 or later; Folio Pro targets Apple Silicon. Both editions are free for now. Windows, iPadOS and iOS versions are coming.
