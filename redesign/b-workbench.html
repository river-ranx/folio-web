FAQ

常见问题

为什么 Pro 不在 App Store？

终端、Git 与 AI CLI 需要派生子进程，沙盒不允许。Pro 使用 Developer ID 签名并经过公证，在官网直接下载。

AI 对话会被 Folio 记录吗？

不会。Folio 不解析、也不持久化 AI 消息，会话由各家 CLI 自行管理，Folio 只负责扫描历史并让你一键续聊。

我的文件会被上传吗？

不会，Folio 100% 本地运行。翻译方面，Apple 系统翻译与本地 Ollama 在本机完成；选择 Gemini CLI 或 Google Cloud 时，待译文本会发送至对应服务。

“文件时光机”和 Git 是什么关系？

它基于 Git，每个工作区独立仓库、独立历史，但界面里只出现版本、备注、同步、恢复。近 24 小时全部保留，往后逐级稀疏；锁定的版本永不清理。

.docx 编辑会丢格式吗？

不会。段落样式、表格、图片、水印都会保留，并存回原 Word 格式。
