FAQ

常见问题

Folio 和 Folio Pro 有什么区别？

免费版专注于查看与轻编辑：14 类格式、标签页、全文搜索，以及 Markdown / Word / 代码编辑。Pro 在此之上加入终端、Git、AI CLI、自动快照、全部翻译后端与任务管理。

为什么 Pro 不在 App Store？

终端、Git 与 AI CLI 需要派生子进程，而 App Store 的沙盒不允许。所以 Pro 以 Developer ID 签名并经过公证，在官网直接下载。

我的文件会被上传吗？

不会。Folio 100% 本地运行。翻译方面，Apple 系统翻译与本地 Ollama 都在本机；若你选择 Gemini CLI 或 Google Cloud，待译文本会发送至对应服务。

编辑 .docx 会破坏格式吗？

不会。.docx 以双向往返的方式编辑，段落样式、表格、图片与水印都会原样保留，并存回原 Word 格式。

支持哪些界面语言？

简体中文、繁體中文（香港 / 台灣）、English、日本語、Deutsch、Español、Français。
