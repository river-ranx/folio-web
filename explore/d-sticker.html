    08 · FAQ

    Ask away.

    Is Folio really free?

    Both editions are free to use today: Folio on the Mac App Store, Folio Pro as a direct download.

    Which one should I get?

    Want to open everything and lightly edit Markdown, Word and code? Get Folio from the App Store. Want a terminal, Git, AI CLIs, automatic versions, full translation and tasks in the same window? Get Folio Pro.

    Do my files leave my Mac?

    Viewing, searching and editing happen on your Mac. The one exception is yours to choose: in Pro, translating with Gemini CLI or Google Cloud sends the text being translated to those services. Apple system translation and local Ollama stay on-device.

    Does Folio read my AI conversations?

    It doesn’t parse or store messages. Pro only lists the session history each CLI leaves locally (~/.claude, ~/.codex, ~/.gemini) so you can resume; every CLI still owns its own sessions.

    Will editing a .docx mess up the formatting?

    It’s built to round-trip: .docx in, .docx out, with paragraph styles, tables, images and watermarks preserved, saved back in the original Word format.

    Do I need to know Git to use versions?

    No. The file time machine speaks in versions, notes, sync and restore — no commits or branches in sight.

    What do I need to run it? Other platforms?

    macOS 15 or later; Folio Pro is for Apple-silicon Macs. Windows, iPadOS and iOS versions are coming soon.
