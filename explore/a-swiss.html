§01Breadth / Index

Nothing your Mac can't open.

Double-click, and instead of “No application is set to open this document”, it opens. Fourteen file types render natively in one window; archives can be browsed and QuickLook covers the rest. Hover or focus a row to see its drawing.

    §02Organise / Tabs & workspaces

    Finder-style tabs that remember everything.

    Try it on the right: scroll the page, switch tabs, switch back.

    • Tabs that remember

      Each tab keeps its own folder, scroll position and last-opened file. Jump between projects without losing your place or breaking your flow.

    • Multi-root workspaces

      Add several folders to one workspace. Each stays its own root in the sidebar; nothing has to move into a single directory first.

    • Colour labels

      Tag files with colour labels and filter by them. A messy directory, sorted at a glance.

    §03Find / Full-text search

    Search inside the file, not just its name.

    One query across every open workspace and format, including the text inside PDF, .docx and .pptx files. The panel below is live: type into it.

    §04Edit / Three editors

    Three editors. What you see is what you save.

    Markdown, Word and code can all be changed in place and saved back to their own format. Both editions include them; items marked PRO are what Folio Pro adds on top.

    • Source ⇄ visual, one switch

      Flip between Markdown source and the WYSIWYG view; focus mode included. Try the switch on the right.

    • Rich tables, math, diagrams

      Add or remove table rows and columns; KaTeX math and Mermaid diagrams work out of the box.

    • Images filed for you

      Pasted or dragged images are written to assets/ and the relative paths stay correct.

    • Outline, find & replace

      Outline navigation, ⌘F find & replace, task lists and links. Export as image. PROalso exports PDF / HTML.

    • .docx in, .docx out

      The editing view is the finished Word document. Paragraph styles, tables, images and watermarks survive the round trip.

    • Native macOS format panel

      Font, size, colour, alignment, line spacing, highlight, zoom. Size and alignment on the right are live.

    • Insert & page setup

      Insert tables, images, page breaks and links; set paper size, margins and orientation.

    • Per-file history

      PROEach Word document gets its own version history to browse and restore.

    • 40+ languages

      Syntax colour and bracket matching, tuned for reading and review.

    • Edit and save in place

      Same editor in both editions: open a file, change it, save it back.

    • One ⌘F find overlay

      The find overlay behaves the same in every editor.

    • Diff & merge

      PROA diff editor with side-by-side and merged views, plus merge-conflict resolution.

    §06Folio Pro only

    A local workbench, in the same window.

    Folio Pro runs outside the App Sandbox, so it can do what a viewer can't: start a shell, talk to Git, host your AI CLIs. The App Store edition does not include them.

    Download Folio Pro↓
    • Claude Code, Codex and Antigravity run as embedded TUIs in the main area.
    • Local session history (~/.claude, ~/.codex, ~/.gemini) is scanned automatically; start or resume from the sidebar.
    • Folio does not parse or store messages; each CLI manages its own sessions.
    • Not installed yet? A setup sheet offers run-or-copy commands and a link to the docs.
    • A real pseudo-terminal (PTY) running zsh.
    • Warp-style command blocks, each with its path and Git branch.
    • Multiple sessions; drag to reorder.
    • After cd, the tab title and working directory follow along.
    • Stage, commit, push, pull, fetch; stage and revert by hunk.
    • Stash, rebase, revert, cherry-pick, branches and tags.
    • Blame, per-file history, merge-conflict resolution.
    • Multiple repositories, one in focus; unified or side-by-side diff.
    • Push preview and protected-branch warnings; native dialogs for HTTPS and SSH credentials.
    • Git underneath, none of its vocabulary: versions, notes, sync, restore.
    • Automatic triggers: 5 s change scan, 30 s debounce, scheduled snapshots, and a final one on quit.
    • 24 h: keep all. 7 days: daily. 30 days: weekly. Older: monthly. Locked versions are never pruned.
    • Optional remote sync with back-off retries; on conflict choose overwrite or keep a backup.
    • Each workspace has its own history; all files by default, allow and deny lists adjustable.
    • Translate a selection or the whole document; the full translation is saved as <name>_translation.md.
    • Four backends: Apple Translation, Gemini CLI, Google Cloud Translation and local Ollama.
    • Side-by-side mode shows source and translation together.
    • Code identifiers, paths and API names are protected from mistranslation; paragraphs translate in parallel.
    • Things-style lists: Inbox, Today, Upcoming, Anytime, Someday, Logbook.
    • Syncs through iCloud.
    • Hand a to-do to an AI agent and let it run.
    • Only in Folio Pro; not in the App Store edition.
