06/WorkbenchPRO

Your whole workflow, one split window.

Folio Pro runs outside the App Store sandbox, so it can spawn processes: a real shell, full Git, and the AI CLIs you already use. Read, edit, run, commit and ask — without switching apps.

AI CLI hub

Claude Code, Codex and Antigravity run as TUIs inside the window. Local session history is found automatically — start or resume from the sidebar.

  • Scans ~/.claude · ~/.codex · ~/.gemini
  • Never parses or stores messages — sessions stay with each CLI
  • Not installed? A guide sheet offers run or copy-command

Built-in terminal

A real PTY running /bin/zsh. Warp-style command blocks with your path and Git branch in the prompt.

  • Multiple sessions, drag to reorder
  • cd keeps title and working directory in sync
  • Shares its plumbing with the AI CLI panes

Full Git

From a single hunk to whole branches, without leaving the window. Multiple repos, one focus.

  • Hunk-level stage & revert, unified or side-by-side diff
  • Stash, rebase, revert, cherry-pick, tags, blame, per-file history
  • Conflict resolution; push preview and protected-branch warning

File time machinePRO

Built on Git, with every Git word hidden — just versions, notes, sync and restore. One history per workspace, with smart retention so it never piles up.

08/FAQ

Questions, answered.

Not here? The App Store page and the Pro release notes are kept up to date.

Q1Is Folio free?

Right now both Folio (Mac App Store) and Folio Pro (direct download) are free.

Q2What’s the difference between Folio and Folio Pro?

Folio is view plus light editing: 14 formats, tabs, full-text search, and Markdown / Word / code editing. Pro adds a terminal, full Git, the AI CLI hub, automatic snapshots, 4 translation backends and tasks — plus code Diff/Merge, Word version history and Markdown export to PDF/HTML.

Q3Do my files leave my Mac?

Viewing, search and editing run on your Mac. Text only leaves it if you choose Gemini CLI or Google Cloud as the translation backend in Pro; Apple translation and local Ollama stay on-device.

AI CLI sessions are managed by each CLI itself — Folio doesn’t parse or store the messages.

Q4Why isn’t Pro in the App Store?

The terminal, Git and AI CLIs need to spawn processes, which the App Store sandbox doesn’t allow. So Pro is Developer ID signed, notarized, and downloaded directly.

Q5Will editing a .docx mess up the formatting?

No — .docx in, .docx out. Paragraph styles, tables, images and watermarks are preserved.

Q6Do I need Claude Code or Codex installed?

To use an AI CLI it needs to be installed on your Mac. If it isn’t, Folio Pro shows a guide with run / copy-command buttons and a docs link.

Q7System requirements? What about Windows and iPad?

macOS 15 or later; Pro is for Apple silicon. Windows, iPadOS and iOS versions are coming.
